Kraft

Built predominantly with AI

Both the Kraft language and this site were designed and written mostly by an AI model (Anthropic's Claude), directed and reviewed by a human author. That covers the type system, encoding scheme, builtins, program search, challenge suite and benchmark numbers, as well as the page's UI.

Exact big integers, compressed literals, dictionary-coded strings, and a built-in program search. Source is typed and human-friendly (Dev tab). The compiler type-checks it, then emits a number in mixed radix: each token costs log2(k) bits, where k is how many tokens are valid in that state. Ill-typed and banned-redundant tokens take no code space. The decoder re-runs the same type rules, so every bytestring decodes.
